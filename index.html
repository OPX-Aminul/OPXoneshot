Pipeline

From one attempt to the global model

1 · Record

Each attempt is logged with signal, lock state, action, success and a reward — validated before it leaves the device.

2 · Queue & Push

Events are written to a durable offline queue, then pushed to Supabase with an idempotent event_id.

3 · Delta Pull

On every run the client pulls only new community rows and incrementally fits them via SGD in ~1 second.

4 · Golden Retrain

CI rebuilds the shared model every 3 days, filters noise, passes a quality gate, then commits to models/.

5 · Distribute

New clones fetch the latest bundled model from GitHub automatically — the global brain, out of the box.

6 · Guard

Footprint monitor, garbage collection and atomic save keep every local model safe and recoverable.
