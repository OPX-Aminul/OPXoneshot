Community Learning Sync

Every user's attempts train one shared golden model, rebuilt by GitHub Actions every 3 days.

1

User runs wifi4

AI attacks autonomously; every attempt becomes a record() event with quality scoring.

2

Supabase idempotent INSERT

Events upload via event_id upsert. Offline queue replays on reconnect. Concurrency lock prevents overlap.

3

Golden Model CI (every 3 days)

GitHub Actions merges all community data, applies quality filter, retrains the model via model_build.py.

4

Cross-validation gate

New model must pass accuracy threshold, then atomic save + automatic commit and push to the repo.

5

All users benefit

Next run pulls the latest community brain. The whole network gets smarter together.

Quick Start

Zero-config install. One command does everything.

# Clone the repository
git clone https://github.com/OPX-Aminul/OPXoneshot.git
cd OPXoneshot
# Install globally (creates wifi4 command)
sudo python3 oneshot.py --install
# Run from anywhere
wifi4
# AI Autonomous Mode (Recommended)
python3 oneshot.py --ai
# Check a router (no attack)
python3 oneshot.py --check BSSID
# Pixie Dust / Online bruteforce
python3 oneshot.py -i wlan0 -b BSSID -P
# Community sync (push + pull + retrain)
python3 oneshot.py --sync
